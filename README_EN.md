# Earth Sciences — bilingual geology learning platform

Open index.html in a modern browser. It is a self-contained file with Arabic and English lessons, quizzes, calculators, simulations and an instructor profile. No build step, npm installation or external scripts are needed.

Use English / العربية in the header to switch languages. The current section and stored learning data are retained. A direct English link can use ?lang=en before the hash, for example index.html?lang=en#professor. Typed notes are not automatically translated.

To publish on GitHub Pages, upload index.html to the repository root, then select Settings → Pages → Deploy from a branch → main → /(root). Replace the old index.html rather than uploading the ZIP itself. If replacing the earlier React project, disable its old deployment workflow and use branch deployment.
